# Controle de Viagens — PRD

## Problema original
Usuário enviou um projeto Flutter de referência ("controle_viagens_flutter") e pediu "criar aplicativo de viagem".
É um diário de bordo de quilometragem para motoristas. Recriado no stack Expo/React Native + FastAPI/MongoDB, UI em português.

## Arquitetura
- Frontend: Expo Router (tabs), React Query, tema dark-first (obsidian #121212 + laranja #FF6D00), fontes Barlow Condensed + DM Sans, ícones Phosphor.
- Backend: FastAPI + MongoDB (Motor). Rotas prefixadas com /api.
- Armazenamento de imagens: N/A (sem uploads).
- Sem autenticação.

## Personas
- Motorista / caminhoneiro que registra viagens diárias e acompanha KM do dia/mês.

## Requisitos centrais (estáticos)
- Registrar viagem: data, hora início/fim, KM inicial, KM final, KM rodados (automático), local de carregamento, local de descanso, observações.
- KM rodados = KM final - KM inicial (somente leitura, atualiza ao vivo). Bloquear KM final < KM inicial.
- Resumo: KM do mês, KM de hoje, viagens no mês, distância total.
- Histórico: lista de viagens (mais recentes primeiro), filtro por mês, excluir (swipe).
